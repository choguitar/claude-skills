# 텍스트 형식

```text
# 이준형 – 꽃밭
Key E

[Verse 1]
|E F# |A E |C#m7 F# |B
이젠 알겠어 꽃이 무언지
나에게 그댄 꽃을 주었네

[Chorus]
|:E F# |B |E F# |B E :|
```

- `# ` 로 시작하는 줄이 곡 제목. 한 파일에 여러 곡을 넣을 수 있다.
- 제목 바로 다음 줄은 곡 정보. 기본은 `Key E` 처럼 Key만 쓰고, 모르면 `Key –`.
  단조는 나란한조 장조를 괄호로 붙인다: `Key Bm (D)`. 괄호 쪽은 조표가 같아 스케일·카포 계산에 쓰고, 앞쪽은 곡의 중심 코드를 알려준다.
  Capo·BPM은 사용자가 값을 알려준 경우에만 ` · `로 이어 붙인다: `Key E · Capo 2 · BPM 90`. 값이 없는 항목은 쓰지 않는다.
- `[`로 시작하면 섹션, `|`로 시작하면 코드 줄, 나머지는 가사. 빈 줄은 무시된다(섹션 위 여백은 스타일이 준다).
- 코드 줄은 마디마다 `|`로 시작한다 — `|` 하나가 한 마디다. 마디 안 코드는 공백으로 나눈다.
  `|` 뒤가 비어 있으면 **앞 코드가 이어지는 빈 마디**다. 마디 수가 곧 원곡 길이라 절대 지우지 않는다. 줄 끝의 `|`도 빈 마디 하나다: `|C | | |` = C 4마디.
  코드 2개인 마디는 빌드가 두 번째 코드를 반 마디 위치(4/4박자 3박)에 맞춘다. 3개 이상은 공백 간격 그대로다.
- 한 줄은 4마디. 5마디 이상이면 빌드가 4마디씩 자동으로 나누고 경고한다.
- 도돌이표는 입력 그대로 적어도 된다: `|:`로 여는 코드 줄부터 `:|`로 닫는 코드 줄(과 그 아래 가사)까지가 반복 구간.
  빌드는 이를 펼쳐서 쓰고, 한 페이지를 넘을 때만 다시 접는다(layout.md 배치 규칙 3).
  반복 끝 `:|`는 마디 끝에 붙는다 — 악보에서는 줄 끝이면 오른쪽 끝에 정렬되고, 줄 중간이면 다음 마디의 `|`와 이어진다.
  한 줄 안의 반복은 `|:C |G :|Am |F`처럼 쓴다(펼치지 않고 그대로 둔다).

## 섹션명

섹션명은 아래 표준 이름만 쓴다. 곡 흐름 순서다.

| 표준 이름 | 쓰임 |
|---|---|
| `[Intro]` | 전주 |
| `[Verse]`, `[Verse 1]`, `[Verse 2]` … | 절. 한 번만 나오면 번호 없이, 여러 번이면 번호를 붙인다 |
| `[Pre Chorus]` | 후렴 직전 빌드업 |
| `[Chorus]` | 후렴 |
| `[Post Chorus]` | 후렴 직후 이어지는 부분 |
| `[Bridge]` | 곡 후반에 한 번 나오는 전환부 |
| `[Interlude]` | 간주 |
| `[Outro]` | 후주. 곡을 끝맺는 마무리(엔딩 코드, 태그) 포함 |

- 오타·변형은 묻지 않고 표준 이름으로 고친다: `Chrous` → `Chorus`, `Pre-Chorus`·`PreChorus` → `Pre Chorus`, `Ending` → `Outro`, 대소문자 차이 등.
- 한글 이름은 뜻이 분명하면 바꾼다: 전주 → `Intro`, 절 → `Verse`, 후렴 → `Chorus`, 간주 → `Interlude`, 후주·엔딩 → `Outro`, 브릿지 → `Bridge`.
- 번호는 Verse에만 붙인다. 합주 중 "2절"처럼 번호로 부르는 섹션이라서다. 다른 섹션은 한 곡에서 내용이 달라도 번호 없이 쓴다 — 가사는 바로 아래 적혀 있고, 위치는 앞의 Verse로 구분된다.
- 섹션명 뒤에 붙은 반복 표시는 유지한다: `[Chorus] x2`.
- 표에 없고 대응도 불분명한 이름(예: `[Rap]`, `[Solo]`)은 그대로 둔다.
- 고친 내용은 결과 보고에 한 줄로 알린다(예: "`Chrous` → `Chorus` 44곳").
